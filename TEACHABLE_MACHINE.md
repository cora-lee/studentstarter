## Legitimate-data workflow

Use only images or audio captured by the students who consent to the project.
Do not substitute web images, generated samples, or copied classmates' data.

1. Copy the exact class names and required sample counts from the course brief.
2. Create one folder per class under a local, untracked `teachable-machine-data/`
   directory.
3. Capture varied examples across the actual team: different positions,
   distances, clothing, lighting, and backgrounds. Keep a separate test set that
   is not uploaded for training.
4. Record a simple manifest with participant code, class, capture date, sample
   count, and consent/retention note. Do not put personal names in public Git.
5. Train in Teachable Machine with the course-required project type and settings.
6. Test with held-out, user-provided examples. Record the actual confusion cases;
   do not report the training preview as independent accuracy.
7. Export only the format named in the brief. Preserve the Teachable Machine
   share link if required, plus the exported model files and labels.
